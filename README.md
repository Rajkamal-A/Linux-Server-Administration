# 🖥️ Linux Server Administration

A collection of hands-on Linux server administration exercises covering
server configuration, network services, file sharing, and remote
resource management.

---

## 📚 Topics Covered

### 1. Apache Web Server
- Apache installation and configuration
- Web server management
- Service control
- Hosting web content

### 2. AutoFS Configuration
- AutoFS concepts
- Automatic filesystem mounting
- Mount point configuration
- Remote filesystem management

### 3. DNS Server
- DNS fundamentals
- DNS server configuration
- Forward and reverse lookups
- Name resolution

### 4. FTP File Transfer
- FTP concepts
- FTP server configuration
- File transfer
- User access and permissions

### 5. SMTP Mail Server
- SMTP fundamentals
- Mail server concepts
- SMTP configuration
- Mail service management

### 6. NFS Server
- Network File System fundamentals
- NFS server configuration
- Exporting directories
- Mounting remote filesystems

### 7. Samba File Sharing
- Samba fundamentals
- SMB/CIFS file sharing
- Samba server configuration
- Windows-Linux file sharing
